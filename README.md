# DreamArchive

DreamArchive 是一个梦境档案项目，包含 Spring Boot 后端和 Vue 前端，用于记录、查询和统计用户的梦境内容，并规划接入 AI 梦境解析、验证码与邮件验证等能力。

## 技术栈

- 后端：Spring Boot 3.5.7、MyBatis、MySQL、Java 17
- 前端：Vue、Vite、TypeScript
- 密码加密：BCrypt
- 数据统计：梦境数量、情绪分布、地点分布、趋势统计

## 当前功能

- 用户注册
- 用户登录
- 修改密码与重置密码基础流程
- 梦境记录保存与查询
- 用户梦境统计接口
- 前端基础页面与 API 对接
